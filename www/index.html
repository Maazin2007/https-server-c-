What's under the hood

Every component built from scratch, no abstractions.

01 — NETWORKING

Raw POSIX sockets

socket(), bind(), listen(), accept() — the same syscalls nginx uses, called directly.

02 — PROTOCOL

Hand-parsed HTTP

No libraries. Parses the raw request string, extracts method and path, builds valid HTTP/1.1 responses.

03 — CONCURRENCY

Thread per client

Each connection gets its own std::thread. Multiple clients handled simultaneously without blocking.

04 — RELIABILITY

Graceful shutdown

Catches SIGINT and SIGTERM. Stops accepting connections, finishes in-flight requests, exits cleanly.

05 — FILE SERVING

Static file server

Maps URL paths to /www directory. Serves HTML, CSS with correct Content-Type headers. Returns proper 404s.

06 — DEPLOYMENT

AWS EC2

Running on a real Linux server. Compiled with g++, exposed on port 8080, publicly accessible.

The accept loop

The core of the server — accepting connections and dispatching threads.

server.cpp 
while (running) {
    // blocks until a client connects
    int clientFd = accept(serverFd, nullptr, nullptr);

    // bad fd means we're shutting down
    if (clientFd < 0) break;

    // hand off to a thread immediately
    // main loop goes back to accept() right away
    std::thread t(handleClient, clientFd);
    t.detach();
}
